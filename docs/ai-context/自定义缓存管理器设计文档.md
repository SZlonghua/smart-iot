# 自定义缓存管理器 — 设计文档

## 一、需求背景

当前项目有两种缓存方式：Spring `@Cacheable` 注解缓存和 `RedisService` 手动缓存，但存在问题：

1. `RedisService` 无接口抽象，无法替换实现，单测无法 mock
2. 注解缓存 Key 格式固定（`cache:name:key`），缺乏灵活性
3. String/Hash/Set 操作散落在各处，缺少统一入口
4. Config 配置缓存需要专门的 Hash 结构管理

目标：设计一套带接口抽象的缓存体系，支持 String/Hash/Set 三种结构，Redis 实现，并可扩展 Config 配置专用存储。

## 二、架构图

```
ICacheManager (缓存管理器)
  ├── getStringCache()      →  IStringCache   — key 在操作中传入
  ├── getHashCache(key)     →  IHashCache     — 绑定 key，field 在操作中传入
  └── getSetCache(key)      →  ISetCache      — 绑定 key，member 在操作中传入

Redis 实现:
  ├── RedisStringCache implements IStringCache
  ├── RedisHashCache   implements IHashCache
  ├── RedisSetCache    implements ISetCache
  └── RedisCacheManager implements ICacheManager

Config 配置存储 (组合 IHashCache):
  ├── IConfigStorageManager  →  getStorage(key)
  ├── IConfigStorage         →  组合 IHashCache + 屏蔽 key，直接 field 操作
  ├── RedisConfigStorage implements IConfigStorage
  └── RedisConfigStorageManager implements IConfigStorageManager
```

## 三、接口定义

### 3.1 ICache（纯标记接口）

```java
/** 缓存标记接口，不定义任何方法 */
public interface ICache {
}
```

### 3.2 IStringCache — 字符串缓存

```java
/**
 * String 结构缓存 — 对应 Redis String。操作直接传入 key。
 */
public interface IStringCache extends ICache {

    String get(String key);

    <T> T getObject(String key, Class<T> clazz);

    void set(String key, String value);

    void set(String key, String value, long seconds);

    void setObject(String key, Object value);

    void setObject(String key, Object value, long seconds);

    boolean delete(String key);

    boolean exists(String key);

    boolean expire(String key, long seconds);

    long getExpire(String key);

    long increment(String key, long delta);
}
```

### 3.3 IHashCache — 哈希缓存（绑定 key）

```java
/**
 * Hash 结构缓存 — 对应 Redis Hash。创建时绑定 key，操作只传 field。
 */
public interface IHashCache extends ICache {

    /** 此 Hash 绑定的 key */
    String getKey();

    String get(String field);

    <T> T getObject(String field, Class<T> clazz);

    void set(String field, String value);

    void setObject(String field, Object value);

    void setAll(Map<String, String> map);

    boolean delete(String... fields);

    boolean exists(String field);

    Set<String> fields();

    Map<String, String> entries();

    long size();
}
```

### 3.4 ISetCache — 集合缓存（绑定 key）

```java
/**
 * Set 结构缓存 — 对应 Redis Set。创建时绑定 key，操作只传 member。
 */
public interface ISetCache extends ICache {

    /** 此 Set 绑定的 key */
    String getKey();

    boolean add(String... members);

    boolean remove(String... members);

    boolean contains(String member);

    Set<String> members();

    long size();
}
```

### 3.5 ICacheManager — 缓存管理器

```java
/**
 * 缓存管理器 — String 不绑 key，Hash/Set 绑 key。
 */
public interface ICacheManager {

    IStringCache getStringCache();

    IHashCache getHashCache(String key);

    ISetCache getSetCache(String key);
}
```

### 3.6 Value — 配置值包装器

```java
/**
 * 配置值包装器 — 链式类型转换，屏蔽原始字符串。
 */
public interface Value {

    /** 获取原始字符串值 */
    String asString();

    /** 转换为 int，null 或非数字返回 0 */
    int asInt();

    /** 转换为 int，null 或非数字返回默认值 */
    int asInt(int defaultValue);

    /** 转换为 long */
    long asLong();

    long asLong(long defaultValue);

    /** 转换为 double */
    double asDouble();

    double asDouble(double defaultValue);

    /** 转换为 boolean（"true"/"1"/"yes" → true） */
    boolean asBoolean();

    boolean asBoolean(boolean defaultValue);

    /** 反序列化为对象 */
    <T> T asObject(Class<T> clazz);

    /** 是否有值（非 null） */
    boolean isPresent();

    /** 如果为空则返回默认值 */
    String orElse(String defaultValue);

    /** 如果为空则使用提供者生成默认值 */
    String orElseGet(Supplier<String> defaultValueSupplier);

    /** 原始值，可能为 null */
    String get();
}
```

### 3.7 IConfigStorage — 配置存储（组合 IHashCache）

```java
/**
 * 配置存储 — 组合 IHashCache，绑定固定 key。
 * getConfig(key) 返回 Value 包装器，支持链式类型转换。
 */
public interface IConfigStorage {

    String getKey();

    /** 获取单个配置值 */
    Value getConfig(String field);

    /** 获取配置值，为空时使用提供者生成并自动写入 */
    Value getConfig(String field, Supplier<String> defaultValueSupplier);

    /** 批量获取配置值 */
    List<Value> getConfigs(String... fields);

    /** 批量获取配置值 */
    List<Value> getConfigs(Collection<String> fields);

    /** 设置单个配置 */
    Boolean setConfig(String field, Object value);

    /** 批量设置配置 */
    Boolean setConfigs(Map<String, Object> values);

    /** 删除配置项 */
    Boolean remove(String... fields);

    /** 获取并删除配置（原子操作） */
    Value getAndRemove(String field);

    /** 检查配置是否存在 */
    Boolean hasConfig(String field);

    /** 获取所有配置 */
    Map<String, Value> getAll();

    /** 获取配置项数量 */
    long size();

    /** 清空所有配置 */
    Boolean clear();
}
```

## 四、Redis 实现

### 4.1 实现要点

| 类 | 说明 |
|---|------|
| `RedisStringCache` | 委托 `RedisTemplate<String, Object>`，key 直接作为 Redis key |
| `RedisHashCache` | 构造时绑定 key，委托 `HashOperations` 按 field 操作 |
| `RedisSetCache` | 构造时绑定 key，委托 `SetOperations` 按 member 操作 |
| `RedisCacheManager` | 持有 StringCache 单例，按需创建/缓存 HashCache/SetCache |
| `RedisConfigStorage` | 组合 `IHashCache` + 绑定固定 key，不继承 |
| `RedisConfigStorageManager` | 内部 Map 管理 `key → RedisConfigStorage` 映射 |

### 4.2 实现要点

- **key 由调用方控制**，实现层不做拼接，直接作为 Redis key 使用
- 所有序列化由 `RedisTemplate` 的 `Jackson2JsonRedisSerializer` 统一处理

### 4.3 RedisStringCache 示例

```java
public class RedisStringCache implements IStringCache {

    private final RedisTemplate<String, Object> redisTemplate;

    @Override
    public String get(String key) {
        Object value = redisTemplate.opsForValue().get(key);
        return value == null ? null : value.toString();
    }

    @Override
    public void set(String key, String value, long seconds) {
        redisTemplate.opsForValue().set(key, value, seconds, TimeUnit.SECONDS);
    }

    @Override
    public boolean delete(String key) {
        return Boolean.TRUE.equals(redisTemplate.delete(key));
    }
    // ...
}
```

### 4.4 RedisHashCache 示例（绑定 key）

```java
public class RedisHashCache implements IHashCache {

    private final String key;
    private final HashOperations<String, String, Object> hashOps;

    public RedisHashCache(String key, HashOperations<String, String, Object> hashOps) {
        this.key = key;
        this.hashOps = hashOps;
    }

    @Override
    public String getKey() { return key; }

    @Override
    public String get(String field) {
        return (String) hashOps.get(key, field);
    }

    @Override
    public void set(String field, String value) {
        hashOps.put(key, field, value);
    }

    @Override
    public Map<String, String> entries() {
        Map<String, Object> all = hashOps.entries(key);
        Map<String, String> result = new LinkedHashMap<>();
        all.forEach((k, v) -> result.put(k, v != null ? v.toString() : null));
        return result;
    }
    // ...
}
```

### 4.5 RedisConfigStorage 示例（组合 + 绑定 key）

```java
public class RedisConfigStorage implements IConfigStorage {

    private final IHashCache hashCache;

    public RedisConfigStorage(IHashCache hashCache) {
        this.hashCache = hashCache;
    }

    @Override
    public IHashCache getHashCache() { return hashCache; }

    @Override
    public String getKey() { return hashCache.getKey(); }

    @Override
    public Value getConfig(String field) {
        return SimpleValue.of(hashCache.get(field));
    }

    @Override
    public Value getConfig(String field, Supplier<String> defaultValueSupplier) {
        Value value = getConfig(field);
        if (!value.isPresent()) {
            String defaultValue = defaultValueSupplier.get();
            hashCache.set(field, defaultValue);
            return SimpleValue.of(defaultValue);
        }
        return value;
    }

    @Override
    public List<Value> getConfigs(String... fields) {
        return getConfigs(Arrays.asList(fields));
    }

    @Override
    public List<Value> getConfigs(Collection<String> fields) {
        List<Value> result = new ArrayList<>(fields.size());
        for (String field : fields) {
            result.add(SimpleValue.of(hashCache.get(field)));
        }
        return result;
    }

    @Override
    public Boolean setConfig(String field, Object value) {
        hashCache.setObject(field, value);
        return true;
    }

    @Override
    public Boolean setConfigs(Map<String, Object> values) {
        if (values == null || values.isEmpty()) return false;
        Map<String, String> map = new HashMap<>();
        values.forEach((k, v) -> map.put(k, v == null ? null : v.toString()));
        hashCache.setAll(map);
        return true;
    }

    @Override
    public Boolean remove(String... fields) {
        return hashCache.delete(fields);
    }

    @Override
    public Value getAndRemove(String field) {
        Value value = getConfig(field);
        hashCache.delete(field);
        return value;
    }

    @Override
    public Boolean hasConfig(String field) {
        return hashCache.exists(field);
    }

    @Override
    public Map<String, Value> getAll() {
        Map<String, String> entries = hashCache.entries();
        Map<String, Value> result = new LinkedHashMap<>();
        entries.forEach((k, v) -> result.put(k, SimpleValue.of(v)));
        return result;
    }

    @Override
    public long size() {
        return hashCache.size();
    }

    @Override
    public Boolean clear() {
        return hashCache.delete(hashCache.fields().toArray(new String[0]));
    }
}
```

### 4.6 SimpleValue — Value 实现

```java
public class SimpleValue implements Value {

    private final Object raw;

    private SimpleValue(Object raw) {
        this.raw = raw;
    }

    /** 工厂方法 */
    public static SimpleValue of(Object raw) {
        return new SimpleValue(raw);
    }

    /** 创建一个空值 */
    public static SimpleValue empty() {
        return new SimpleValue(null);
    }

    @Override
    public String get() {
        return raw == null ? null : raw.toString();
    }

    @Override
    public String asString() { return get(); }

    @Override
    public int asInt() { return asInt(0); }

    @Override
    public int asInt(int defaultValue) {
        if (raw == null) return defaultValue;
        if (raw instanceof Number) return ((Number) raw).intValue();
        try { return Integer.parseInt(raw.toString()); } catch (NumberFormatException e) { return defaultValue; }
    }

    @Override
    public long asLong() { return asLong(0L); }

    @Override
    public long asLong(long defaultValue) {
        if (raw == null) return defaultValue;
        if (raw instanceof Number) return ((Number) raw).longValue();
        try { return Long.parseLong(raw.toString()); } catch (NumberFormatException e) { return defaultValue; }
    }

    @Override
    public double asDouble() { return asDouble(0.0); }

    @Override
    public double asDouble(double defaultValue) {
        if (raw == null) return defaultValue;
        if (raw instanceof Number) return ((Number) raw).doubleValue();
        try { return Double.parseDouble(raw.toString()); } catch (NumberFormatException e) { return defaultValue; }
    }

    @Override
    public boolean asBoolean() { return asBoolean(false); }

    @Override
    public boolean asBoolean(boolean defaultValue) {
        if (raw == null) return defaultValue;
        if (raw instanceof Boolean) return (Boolean) raw;
        String lower = raw.toString().toLowerCase();
        return "true".equals(lower) || "1".equals(lower) || "yes".equals(lower);
    }

    @Override
    @SuppressWarnings("unchecked")
    public <T> T asObject(Class<T> clazz) {
        if (raw == null) return null;
        if (clazz.isInstance(raw)) return (T) raw;
        return JSON.parseObject(raw.toString(), clazz);
    }

    @Override
    public boolean isPresent() { return raw != null; }

    @Override
    public String orElse(String defaultValue) {
        return raw != null ? get() : defaultValue;
    }

    @Override
    public String orElseGet(Supplier<String> defaultValueSupplier) {
        return raw != null ? get() : defaultValueSupplier.get();
    }
}
```

## 五、类图总结

```
ICache (纯标记，无方法)

ICache (纯标记，无方法)

IStringCache (extends ICache)
    ├── get(key)/set(key,val)/delete(key)/exists/expire — key 在操作中传
    └── RedisStringCache

IHashCache (extends ICache)
    ├── getKey() — 创建时绑定 key，操作只传 field
    ├── get(field)/set(field,val)/delete/fields/entries/size
    └── RedisHashCache

ISetCache (extends ICache)
    ├── getKey() — 创建时绑定 key，操作只传 member
    ├── add(member)/remove/contains/members/size
    └── RedisSetCache

Value (配置值包装器)
    ├── asString()/asInt()/asLong()/asDouble()/asBoolean()
    ├── orElse(defaultValue) / isPresent() / asObject(Class)
    └── SimpleValue

IConfigStorage (组合 IHashCache + Value)
    ├── getKey()
    ├── getConfig(field) → Value    ← 链式转换
    ├── setConfig(field,val)/removeConfig(field)/hasConfig(field)
    └── RedisConfigStorage

ICacheManager
    ├── getStringCache()            — 不绑 key
    ├── getHashCache(key)           — 绑 key
    └── getSetCache(key)            — 绑 key
    └── RedisCacheManager

IConfigStorageManager
    ├── getStorage(key)/removeStorage(key)/getKeys()
    └── RedisConfigStorageManager
```

## 六、使用示例

```java
// ===== String — 不绑 key，key 在操作中传 =====
IStringCache strCache = cacheManager.getStringCache();
strCache.set("device:status_6", "online", 3600);
String status = strCache.get("device:status_6");

// ===== Hash — getHashCache(key) 绑 key，操作只传 field =====
IHashCache deviceCache = cacheManager.getHashCache("device:6");
deviceCache.set("name", "温度传感器");
deviceCache.set("status", "online");
Map<String, String> allFields = deviceCache.entries();

// ===== Set — getSetCache(key) 绑 key，操作只传 member =====
ISetCache onlineSet = cacheManager.getSetCache("online_devices");
onlineSet.add("6", "7", "8");
boolean online = onlineSet.contains("6");

// ===== Config — Value 链式转换 =====
IConfigStorage sysConfig = configStorageManager.getStorage("system");

// 单值读写
sysConfig.setConfig("timeout", 30);                             // Object 自动序列化
int timeout = sysConfig.getConfig("timeout").asInt();           // 30

// 带默认值（不存在时自动写入）
int port = sysConfig.getConfig("port").asInt(8080);
// 带空值提供者（不存在时调用 Supplier 生成并写入）
String token = sysConfig.getConfig("token", () -> UUID.randomUUID().toString())
                        .asString();

// 批量操作
sysConfig.setConfigs(Map.of("host", "localhost", "port", 6379));
List<Value> values = sysConfig.getConfigs("host", "port");

// getAndRemove 原子操作
Value oldValue = sysConfig.getAndRemove("old_key");

// 获取全部
Map<String, Value> all = sysConfig.getAll();
all.forEach((k, v) -> log.info("{}={}", k, v.asString()));

// 清空
sysConfig.clear();
```

## 七、与现有 RedisService 的关系

| 现有 | 新体系 |
|------|--------|
| `RedisService.get(key)` | `strCache.get(key)` |
| `RedisService.mset(key, field, val)` | `hashCache.set(key, field, val)` |
| 无 Set 操作 | `setCache.add(key, member)` |
| 无类型安全的配置读取 | `configStorage.getInteger(field)` |
| 不可替换实现 | 接口抽象，可 mock / 切换 |
