# 物模型校验设计（下发：写属性 / 功能调用 / 读属性；上报：属性上报 / 事件上报）

> 下发链路中的调用方设计见 [设备命令下发解决方案设计](./设备命令下发解决方案设计.md) 3.2 / 六章，上报链路调用方见本文档六章 6.2。本文档独立描述**物模型内部校验**的设计与修改文件。
>
> **实施分两阶段**（避免下发链路与校验同时修改风险过大，出问题无法定位是哪侧导致）：
> - **第一阶段（随 [设备命令下发解决方案设计](./设备命令下发解决方案设计.md) 落地）**：仅声明校验方法，**内部不实现**（default 返回空列表，见下发文档六章），先打通下发链路 — 本阶段只改 `ThingsMetadata` / `DataType` 两个文件
> - **第二阶段（按本文档落地）**：实现校验方法内部逻辑（物模型内部逐项校验 + 各 `DataType.validateValue` 递归实现），操作对象调用侧零改动

---

## 一、背景与现状

| 能力 | 现状 | 缺口 |
|------|------|------|
| `DataType.validate()`（Validatable） | 只校验类型**定义**本身（如 int 的 min ≤ max、enum 枚举值数组合法性、object 子属性 id 重复） | **不校验传入值**（用户提交的属性值/参数值） |
| `DataTypeCodec` | 仅负责 `IJsonNode ↔ DataType` 序列化 | 无值校验能力 |
| 校验入口 | 无 — 物模型自身不能校验待写入的值 | 操作对象/业务层需要自行遍历物模型校验，逻辑分散 |
| 上报链路 | `DefaultDecodedClientMessageHandler.handle()` 解码后直接 `eventBus.publishAsync`，无任何校验 | 非法上报数据（属性/事件）进入事件总线 → 脏数据入库 |

**结论**：校验是物模型内部的事 — 在 `ThingsMetadata` 上提供校验方法，内部按物模型内容逐项校验，再**递归调用各自数据类型的 `validateValue`**。下发（写/读属性、功能调用）与上报（属性/事件上报）共用同一套递归校验。

## 二、总体设计

```
操作对象 send() 前（见下发文档 3.2）
  │ 取物模型（registry.getDevice(deviceId) → getMetadata()）
  ▼
ThingsMetadata.validateReadProperties / validateProperties / validateFunction   ← 校验入口（物模型内部）
  │ 内部遍历：属性/功能存在性、accessMode、参数名校验、必填齐全
  ▼
PropertyMetadata.getValueType().validateValue(value)                            ← 递归叶子（各类型值校验）
FunctionParamMetadata.getValueType().validateValue(value)
  │ int 范围 / float 范围 / string 长度 / bool 类型 / enum 枚举值 / date 格式 / array、object 递归
  ▼
返回 List<String> 错误列表（空 = 合法，风格对齐 Validatable.validate()）
  ▼
操作对象 checkErrors：非空 → 抛 BusinessException → GlobalExceptionHandler 转错误响应，不下发
```

设备上报（MqttServerDeviceGateway 解码后）
  │ ReportPropertyMessage / EventMessage
  ▼
eventBus.publishAsync(message)（上报消息发布后由事件监听器消费）
  │ 后续：事件监听器（eventListener）消费时调用校验 —— 本文档仅预留校验能力
  ▼
ThingsMetadata.validateReportProperties / validateEvent  ← 预留校验方法（见四章）
  │ 属性存在性 / 事件存在性
  ▼
PropertyMetadata.getValueType().validateValue(value) / EventMetadata.getValueType().validateValue(data)
  ▼
校验失败 → log.warn + 丢弃（不落库）；通过 → 正常业务处理
```

设计要点：

1. **校验入口在 `ThingsMetadata`** — 五个 default 方法（`validateReadProperties` / `validateProperties` / `validateReportProperties` / `validateEvent` / `validateFunction`），内部使用自身物模型内容（`getPropertyOrNull` / `getFunctionOrNull` / `getEventOrNull` / `getInputs`），无需外部传参
2. **值校验在 `DataType`** — 新增 `validateValue(Object)`，各类型实现；`ArrayDataType`/`ObjectDataType` 递归调用内部元素/属性的 `validateValue`
3. **返回错误列表而非抛异常** — 对齐 `Validatable.validate()` 风格，一次返回全部错误；由调用方决定抛错时机（操作对象统一 `BusinessException`）
4. **调用方零校验逻辑** — 操作对象只调方法 + `checkErrors`，物模型内部如何校验与调用方无关
5. **上报校验仅预留能力** — `validateReportProperties` / `validateEvent` 随物模型提供（同本套递归机制），调用方（事件监听器）后续落地：下发校验失败抛 `BusinessException` 转错误响应；上报数据来自设备端，校验失败**丢弃 + 日志告警**（脏数据不落库）

## 三、校验内容

| 场景 | 校验方法 | 校验规则 |
|------|------|---------|
| 读属性 | `validateReadProperties(properties)` | 属性 ID 需在物模型中存在（`getPropertyOrNull`），否则报错 `属性 [xxx] 不存在` |
| 写属性 | `validateProperties(properties)` | ① 属性存在；② `accessMode` 非只读（`"readOnly"` 不可写）；③ 值按 `property.getValueType().validateValue(value)` 递归校验 |
| 功能调用 | `validateFunction(functionId, params)` | ① 功能存在（`getFunctionOrNull`）；② **参数名校验**：入参 key 必须命中 `function.getInputs()` 中 `FunctionParamMetadata.getId()`，未知参数报错；③ 必填参数齐全（`isRequired()` 的参数必须有值）；④ 每个参数值按 `param.getValueType().validateValue(value)` 递归校验 |
| 属性上报 | `validateReportProperties(properties)` | ① 属性存在（`getPropertyOrNull`）；② 值按 `property.getValueType().validateValue(value)` 递归校验。**不做只读限制** — `readOnly` 仅限制平台下发写操作，设备上报不受限 |
| 事件上报 | `validateEvent(event, data)` | ① 事件存在（`getEventOrNull`）；② 数据按 `event.getValueType().validateValue(data)` 递归校验（object 事件递归子属性） |

## 四、ThingsMetadata 校验方法（修改 `metadata/ThingsMetadata.java`）

接口新增五个 default 方法 + `prefix` 辅助（错误统一加"属性/参数/事件"前缀）：

```java
public interface ThingsMetadata extends Metadata, Jsonable {

    List<? extends PropertyMetadata> getProperties();

    PropertyMetadata getPropertyOrNull(String id);

    FunctionMetadata getFunctionOrNull(String id);

    /** 校验读取的属性 — 每个属性需在物模型中存在，返回错误列表（空 = 合法） */
    default List<String> validateReadProperties(List<String> properties) {
        List<String> errors = new ArrayList<>();
        for (String propertyId : properties) {
            if (getPropertyOrNull(propertyId) == null) {
                errors.add("属性 [" + propertyId + "] 不存在");
            }
        }
        return errors;
    }

    /** 校验写入的属性值 — 属性存在 + 非只读 + 值按各自 DataType.validateValue 递归校验，返回错误列表 */
    default List<String> validateProperties(Map<String, Object> properties) {
        List<String> errors = new ArrayList<>();
        for (Map.Entry<String, Object> entry : properties.entrySet()) {
            PropertyMetadata property = getPropertyOrNull(entry.getKey());
            if (property == null) {
                errors.add("属性 [" + entry.getKey() + "] 不存在");
                continue;
            }
            if ("readOnly".equals(property.getAccessMode())) {
                errors.add("属性 [" + entry.getKey() + "] 为只读，不可写");
                continue;
            }
            // 递归：值按属性的值类型校验（int 范围 / bool 类型 / enum 枚举值 / object 子属性等）
            errors.addAll(prefix("属性 [" + entry.getKey() + "]", property.getValueType().validateValue(entry.getValue())));
        }
        return errors;
    }

    /** 校验上报的属性值 — 属性存在 + 值按各自 DataType.validateValue 递归校验，返回错误列表（不做只读限制：readOnly 仅限制平台下发，设备上报允许） */
    default List<String> validateReportProperties(Map<String, Object> properties) {
        List<String> errors = new ArrayList<>();
        for (Map.Entry<String, Object> entry : properties.entrySet()) {
            PropertyMetadata property = getPropertyOrNull(entry.getKey());
            if (property == null) {
                errors.add("属性 [" + entry.getKey() + "] 不存在");
                continue;
            }
            // 递归：值按属性的值类型校验（与 validateProperties 一致，仅缺只读检查）
            errors.addAll(prefix("属性 [" + entry.getKey() + "]", property.getValueType().validateValue(entry.getValue())));
        }
        return errors;
    }

    /** 校验上报的事件 — 事件存在 + 数据按事件值类型 validateValue 递归校验，返回错误列表 */
    default List<String> validateEvent(String event, Object data) {
        List<String> errors = new ArrayList<>();
        EventMetadata metadata = getEventOrNull(event);
        if (metadata == null) {
            errors.add("事件 [" + event + "] 不存在");
            return errors;
        }
        errors.addAll(prefix("事件 [" + event + "]", metadata.getValueType().validateValue(data)));
        return errors;
    }

    /** 校验功能调用参数 — 功能存在 + 参数名匹配 + 必填齐全 + 值按各自 DataType.validateValue 递归校验，返回错误列表 */
    default List<String> validateFunction(String functionId, Map<String, Object> params) {
        List<String> errors = new ArrayList<>();
        FunctionMetadata function = getFunctionOrNull(functionId);
        if (function == null) {
            errors.add("功能 [" + functionId + "] 不存在");
            return errors;
        }
        Map<String, FunctionParamMetadata> inputs = function.getInputs().stream()
                .collect(Collectors.toMap(FunctionParamMetadata::getId, p -> p));
        // ① 参数名校验 + 值校验（递归）
        for (Map.Entry<String, Object> entry : params.entrySet()) {
            FunctionParamMetadata param = inputs.get(entry.getKey());
            if (param == null) {
                errors.add("功能 [" + functionId + "] 不存在参数 [" + entry.getKey() + "]");
                continue;
            }
            errors.addAll(prefix("参数 [" + entry.getKey() + "]", param.getValueType().validateValue(entry.getValue())));
        }
        // ② 必填参数齐全
        for (FunctionParamMetadata param : function.getInputs()) {
            if (param.isRequired() && !params.containsKey(param.getId())) {
                errors.add("功能 [" + functionId + "] 缺少必填参数 [" + param.getId() + "]");
            }
        }
        return errors;
    }

    /** 错误信息统一加前缀（指明是哪个属性/参数） */
    default List<String> prefix(String name, List<String> errors) {
        return errors.stream().map(e -> name + " " + e).collect(Collectors.toList());
    }
}
```

## 五、DataType.validateValue（修改 `metadata/type/` 包）

### 5.1 接口新增（修改 `DataType.java`）

```java
public interface DataType extends Validatable {

    /** 类型标识 */
    String getType();

    /** 值校验 — 校验传入值是否符合该类型约束（int 范围 / bool 类型 / enum 枚举值等），返回错误列表（空 = 合法） */
    List<String> validateValue(Object value);
}
```

> 现有 `validate()`（Validatable）保持不变 — 仍校验类型定义本身。

### 5.2 各类型实现

| 类型 | 修改文件 | 校验内容 |
|------|------|------|
| int | `IntDataType.java` | 值须为 Number + min/max 范围 |
| long | `LongDataType.java` | 值须为 Number + min/max 范围 |
| float | `FloatDataType.java` | 值须为 Number + min/max 范围 |
| double | `DoubleDataType.java` | 值须为 Number + min/max 范围 |
| string | `StringDataType.java` | 值须为 String + maxLength 长度 |
| boolean | `BooleanDataType.java` | 值须为 Boolean |
| enum | `EnumDataType.java` | 值须命中 `elements` 的枚举值 |
| date | `DateDataType.java` | 值须为字符串且可按 `format` 解析（默认 `yyyy-MM-dd HH:mm:ss`） |
| array | `ArrayDataType.java` | 值须为集合，逐元素**递归** `elementType.validateValue` |
| object | `ObjectDataType.java` | 值须为 Map，按 `properties` **递归** `validateValue` |

数值类型实现（以 `IntDataType` 为例，Long/Float/Double 同构 — 仅数值取值与 min/max 类型不同）：

```java
// IntDataType（long/float/double 同构：longValue()/floatValue()/doubleValue() + 各自 min/max 类型）
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (!(value instanceof Number)) {
        errors.add("类型应为 int，实际: " + value);
        return errors;
    }
    int v = ((Number) value).intValue();
    if (min != null && v < min) { errors.add("不能小于 " + min); }
    if (max != null && v > max) { errors.add("不能大于 " + max); }
    return errors;
}
```

字符串与布尔：

```java
// StringDataType
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (!(value instanceof String)) {
        errors.add("类型应为 string，实际: " + value);
        return errors;
    }
    if (maxLength != null && ((String) value).length() > maxLength) {
        errors.add("长度不能超过 " + maxLength);
    }
    return errors;
}

// BooleanDataType
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (!(value instanceof Boolean)) {
        errors.add("类型应为 boolean，实际: " + value);
    }
    return errors;
}
```

枚举与日期：

```java
// EnumDataType
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (elements == null || elements.stream().noneMatch(e -> e.getValue().equals(String.valueOf(value)))) {
        errors.add("不在枚举值范围内: " + value);
    }
    return errors;
}

// DateDataType
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (!(value instanceof String)) {
        errors.add("类型应为 date 字符串，实际: " + value);
        return errors;
    }
    String pattern = StringUtils.isNotBlank(format) ? format : "yyyy-MM-dd HH:mm:ss";
    try {
        new SimpleDateFormat(pattern).parse((String) value);
    } catch (ParseException e) {
        errors.add("日期格式不合法，应为: " + pattern + "，实际: " + value);
    }
    return errors;
}
```

递归类型：

```java
// ArrayDataType — 逐元素递归 elementType.validateValue
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (!(value instanceof Iterable)) {
        errors.add("类型应为 array，实际: " + value);
        return errors;
    }
    if (elementType == null) {
        return errors;    // 定义校验（validate()）已覆盖 elementType 为空
    }
    int i = 0;
    for (Object item : (Iterable<?>) value) {
        final int index = i;
        errors.addAll(elementType.validateValue(item)
                .stream().map(e -> "elements[" + index + "] " + e).collect(Collectors.toList()));
        i++;
    }
    return errors;
}

// ObjectDataType — 按子属性递归 validateValue（可选字段缺省不校验）
@Override
public List<String> validateValue(Object value) {
    List<String> errors = new ArrayList<>();
    if (!(value instanceof Map)) {
        errors.add("类型应为 object，实际: " + value);
        return errors;
    }
    Map<?, ?> map = (Map<?, ?>) value;
    if (properties != null) {
        for (ObjectProperty prop : properties) {
            Object v = map.get(prop.getId());
            if (v == null) {
                continue;   // 可选子属性缺省不校验
            }
            errors.addAll(prop.getValueType().validateValue(v)
                    .stream().map(e -> "properties[" + prop.getId() + "] " + e).collect(Collectors.toList()));
        }
    }
    return errors;
}
```

## 六、调用方（下发 → 操作对象；上报 → 预留，后续事件监听器）

### 6.1 下发（操作对象，见下发文档 3.2）

三个操作对象 `send()` 前取物模型后只调方法 + 抛错，无任何校验细节：

```java
.doOnNext(metadata -> checkErrors(metadata.validateReadProperties(properties)))   // 读属性
.doOnNext(metadata -> checkErrors(metadata.validateProperties(properties)))       // 写属性
.doOnNext(metadata -> checkErrors(metadata.validateFunction(functionId, params))) // 功能调用

private void checkErrors(List<String> errors) {
    if (CollUtil.isNotEmpty(errors)) {
        throw new BusinessException(String.join("; ", errors));
    }
}
```

### 6.2 上报（预留校验能力，调用方后续落地）

上报校验能力已随物模型提供：`validateReportProperties(Map)` / `validateEvent(String, Object)`（见四章），**本设计不涉及上报调用方**。后续由事件监听器（eventListener）消费 `ReportPropertyMessage` / `EventMessage` 时调用 — 调用方式与 6.1 一致，仅错误处理不同：

```java
// 后续事件监听器内（伪代码，由事件监听器设计文档落地）
.doOnNext(metadata -> checkReportErrors(metadata.validateReportProperties(report.getProperties())))
.doOnNext(metadata -> checkReportErrors(metadata.validateEvent(event.getEvent(), event.getData())))

/** 上报校验失败 → 日志告警 + 丢弃（数据来自设备端，不抛异常，脏数据不落库） */
private void checkReportErrors(List<String> errors) {
    if (CollUtil.isNotEmpty(errors)) {
        log.warn("上报数据校验失败，消息已丢弃: {}", String.join("; ", errors));
        // 终止后续处理，不落库
    }
}
```

> 子设备上报（`ChildDeviceMessage` 解包后）同样走此校验 — 取物模型时使用子设备 deviceId（解包后消息的 deviceId 已是子设备），校验规则与直连设备一致。

## 八、验证方案

1. **编译**：`mvn compile -pl sa-base -o -q`
2. **读属性**：读取物模型不存在的属性 → 报 `属性 [xxx] 不存在`，不下发
3. **写属性**：① 不存在的属性 → 报错；② 只读属性（accessMode=readOnly）→ 报 `为只读，不可写`；③ 值类型错误（int 属性传字符串、超 min/max 范围）→ 报具体错误；④ object 类型子属性递归校验（子属性值非法 → 报 `properties[xxx] ...`）
4. **功能调用**：① 不存在的功能 → 报错；② 未知参数名 → 报 `不存在参数 [xxx]`；③ 缺少必填参数 → 报 `缺少必填参数 [xxx]`；④ 参数值类型错误 → 报具体错误；⑤ enum 参数传非枚举值 → 报 `不在枚举值范围内`
5. **递归**：array 元素 / object 子属性非法值逐层报错，一次返回全部错误（`; ` 分隔）
6. **下发拦截**：校验失败设备收不到任何消息（`MqttServerDeviceGateway` 无下行日志）
7. **属性上报校验方法**：直接调用 `validateReportProperties` — ① 不存在属性 → 报 `属性 [xxx] 不存在`；② 非法值（int 传字符串 / 超 min/max）→ 报具体错误；③ 只读属性 → **不报错**（只读仅限制平台下发，不限制设备上报）
8. **事件上报校验方法**：直接调用 `validateEvent` — ① 不存在事件 → 报 `事件 [xxx] 不存在`；② 数据不合法（int 事件传字符串 / object 子属性非法）→ 报具体错误；③ 合法 → 空错误列表
9. **监听器集成**（后续事件监听器文档）：上报消息经校验后落库，非法数据丢弃 — 本项待事件监听器落地后验证
